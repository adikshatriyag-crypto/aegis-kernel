Stop Rogue AI Agent Tool Execution
Before It Touches the OS

When you give an AI agent access to bash, python, or file tools, a prompt injection can read your .env keys or wipe disk. AegisKernel wraps agent tools in deterministic capability tokens, dropping unauthorized syscalls in microsecond speed with zero LLM latency and zero token cost.

Drop-in Compatibility
# 1. Install via pip: pip install aegis-kernel from aegis import AegisShield, SecurityPolicy # 2. Grant scoped workspace capability token (Least Privilege) shield = AegisShield(policy=SecurityPolicy.strict(allowed_paths=["./data", "./workspace"])) # 3. Protect tool: unauthorized syscalls (.env theft, rm -rf, reverse shells) are killed instantly @shield.protect_tool def execute_agent_tool(command: str): return subprocess.run(command, shell=True, capture_output=True)
